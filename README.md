# Shopify 优化上新 Skill

用于协助 Codex 整理 Shopify 商品 CSV，优化商品文案、处理图片顺序，并在交付前检查导入文件。

## 使用方式

安装 Skill 后，向 Codex 提供源 CSV，并说明本批次的处理要求：

> 使用 $shopify-optimize-launch 优化这份上新 CSV，保留商品后背图，完成检查后输出导入文件和验证结果。

该 Skill 用于文件准备和校验。生成文件不等于已导入或发布商品；线上操作需要用户明确授权。

## 主要功能

- 优化标题、描述、SEO 和图片说明。
- 按配置整理商品字段并拆分导入文件。
- 保留商品后背图，包括空白后背图。
- 保留源图库相对顺序，检查颜色与变体图片绑定。
- 检查价格格式、图片顺序和分类映射。

图片顺序校验不能替代图片完整性核对，交付前仍需对照源文件检查遗漏。

## 更新方式

通过 Git 安装的用户，可在本地 Skill 仓库中执行：

```powershell
 git status --short
 git pull --ff-only origin main
```

如有本地修改，先核对并保留，再合并更新。通过 ZIP 安装时，应更新完整 Skill 文件夹。

更新 Skill 不会自动修改此前的导入文件或已上架商品。
